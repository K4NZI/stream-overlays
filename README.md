## HenrikDev API Anahtarı Nasıl Alınır?

BERKBASE Valorant HUD sisteminde rank ve oyuncu istatistiklerini göstermek için HenrikDev API kullanılabilir.

**API anahtarı alma adımları:**

1. **HenrikDev'in resmî sitesine gir:** https://docs.henrikdev.xyz/
2. Dokümantasyondaki API erişimi ve kimlik doğrulama (Authentication) bölümünü aç.
3. API anahtarı almak için belirtilen güncel başvuru veya erişim yöntemini takip et. Erişim koşulları değişebileceğinden, dokümantasyonda belirtilen yöntemi esas al.
4. Anahtarını aldıktan sonra bunu HUD veya arka uç sunucusunun API yapılandırmasına ekle.
5. API anahtarını herkese açık HTML/JavaScript dosyalarına, GitHub deposuna veya yayınlanan overlay bağlantısına doğrudan koyma. Anahtar gizli tutulmalı; mümkünse istekler bir arka uç üzerinden yapılmalı.

**Önemli:** API anahtarı almak, bütün Valorant verilerinin otomatik olarak erişilebilir olacağı anlamına gelmez. Oyuncu adı, tag, hesap erişimi ve ilgili uç noktanın koşulları gibi gereklilikler kullanılan verilere göre değişebilir.

Resmî kaynak: https://docs.henrikdev.xyz/
