# BERKBASE Stream Overlays

BERKBASE yayın araçları için ana sayfa.

## GitHub Pages kurulumu
1. Depodaki dosyaları ve `products` klasörünü GitHub deposunun kök dizinine yükle.
2. `index.html` kök dizinde bulunmalı.
3. Repository → Settings → Pages → Deploy from a branch → `main` / `/(root)` seç.
4. Ana sayfa adresi: `https://k4nzi.github.io/berkbase-valorant-overlay/`

Social Popup Rotator: `products/social-popup-rotator.html`
Valorant HUD: `https://k4nzi.github.io/berkbase-valorant-overlay/` (mevcut ayrı sayfa)
